How it works

  1. Exploit a challenge on the target app (the vulnerable zone, on port 5001).
  2. Copy the flag string it reveals.
  3. Submit it on your dashboard here. A short write-up is required, and hints cost points.

What's inside

7 challenges

SQL injection, reflected and stored XSS, IDOR, command injection, path traversal and a chained exploit.

Learn the fix

Every challenge is mapped to the OWASP Top 10 with a plain-English "how to prevent it".

Live scoreboard

Points, a hint economy and a scoreboard that refreshes as the class plays.
